## 적용 기준

- 본문은 Pretendard, 제목은 고운바탕 Bold. 고운바탕은 Google Fonts 원본을 WOFF2로 변환했으며 라이선스는 `fonts/GowunBatang-LICENSE.txt`에 보관합니다.
- 한지는 옅게, 글자는 진한 먹 갈색으로 표시합니다. 주요 행동은 나무 버튼, 보조 행동은 한지 버튼, 선택 상태는 녹색 테두리와 배경으로 구분합니다.
- 장식 이미지는 보조 기술에서 숨기고, 조작의 이름은 별도 텍스트와 접근성 이름으로 제공합니다.
- 기존 인물, 실제 확률 돌림판, 개인 기록, 공동 교실 권한, PNG/JSON 저장은 그대로 연결합니다.
- PC와 768·390·320px 화면에서 시작 화면, 여섯 활동 단계, 교사용 화면의 배치와 스크롤을 확인합니다.

아이콘 보완: 첫 원본 `exec-e620acda-5d31-425b-9041-a08edbfb95c3.png`에서 칸 경계에 인접한 그림 조각이 보이는 것을 화면 검토로 확인했습니다. 이미지 생성 편집으로 각 칸의 투명 여백을 늘리고, 미세한 장식을 정리한 위 보완 원본을 적용했습니다.
