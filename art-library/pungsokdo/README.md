# 풍속도 그림 자료

사용자가 제공한 두 이미지 ZIP에서 현대 물품이 없는 인물 자료를 선별했다. 원본은 [모두의 풍속도](https://pungsokdo.com/)이며 이용 범위는 [저장소 출처 안내](../../ATTRIBUTION.md)를 따른다.

## 포함한 자료

- 원본 이미지 **2,345개**, 21,191,578 bytes (약 20.21 MiB). PNG·SVG를 수정 없이 원본 경로에 보관한다.
- 개별 동작 **38개**의 썸네일. 이 중 **25개**는 업로드에 포함된 의상·머리·표정·얼굴 윤곽 레이어도 있다.
- 공용 의상·머리·표정 선택 이미지, 검토한 그룹 대표 썸네일.
- [선별 기준과 제외 사유](selection.json), [자료 색인](index.json), [동작별 파일 목록](manifests/result/).

휴대전화, 카메라, 헤드셋, 게임기, 마이크, 현대 기타·드럼, 스케이트·킥보드·야구 글러브, 현대 휠체어, 일회용 음료 컵, 햄버거, 현대 응원 도구가 있는 **39개 동작**은 제외했다. 찜질방 양머리도 공용 선택 그림과 모든 동작의 부품에서 제외했다. 일부 그룹 대표 그림에도 현대 물품이 있어 개별 동작과 따로 검토했다.

기준은 **현대 물품의 유무**다. 물품 없는 춤, 달리기, 균형 잡기, 손가락·하트 동작은 포함한다. 모든 동작이 조선 시대에 실제로 행해졌다는 뜻은 아니다. 원본 서비스의 배경·합성 스프라이트·UI·로고는 이번 자료집에 포함하지 않았다.

## 파일 구조

```text
assets/images/result/<동작>/
  clothes/       의상 채색 SVG와 윤곽 PNG
  hairs/         머리·모자 채색 SVG와 윤곽 PNG
  emotions/      표정 PNG
  skintones/     얼굴 윤곽 PNG
assets/images/poses/thumbs/    검토한 동작 썸네일
assets/images/options/        선택용 그림
manifests/                    원본 URL·크기·SHA-256, 동작/종류별 분리
```

SVG의 기준 좌표는 360×360이며 PNG 레이어는 대체로 720×720이다. 같은 동작의 부품끼리 합성한다. 채색 변수는 `--top-color`, `--bottom-color`, `--layer-color`, `--hair-color`다. `hwangchosam`과 `nainbok`은 채색 SVG가 없는 고정색 의상이다.

## 앱에 연결할 때

이 폴더는 재사용을 위한 원본 자료집이다. `index.html`에서 로드하지 않으며 새 동작을 자동으로 선택 목록에 추가하지 않는다. 현재 앱의 24개 동작은 별도의 기존 `assets/*.js`, `catalog.js`, `art-layout.js`를 사용한다.

업로드에는 몸·얼굴 피부 벡터와 추가 관모의 기준 좌표가 없다. `index.json`의 `resultFiles`가 0보다 커도 새 동작을 바로 완성 인물로 합성할 수 있는 것은 아니다. 앱에 추가하려면 피부 벡터와 좌표를 준비하고 의상·머리·표정 조합 및 PNG 저장을 확인한다. 썸네일만 받은 수공예·전통 악기·앉기·아이 돌보기 동작 때문에 앱의 기존 완성 부품을 삭제하거나 덮어쓰지 않는다.

## 검증과 다시 가져오기

```sh
python scripts/pungsokdo.py verify
```

파일별 크기·SHA-256, 실제 파일과 색인의 일치, 제외한 동작·머리 부품의 유입 여부를 검사한다. 명령은 저장소 루트에서 실행한다.

처음 가져올 때는 `index.json`과 `assets/`, `manifests/`가 없는 작업 사본에서 아래 명령을 사용한다. 원본 디렉터리에는 `images.jsonl`과 해시 이름의 추출 이미지가 있어야 한다. 알 수 없는 동작은 자동으로 포함하지 않는다.

```sh
python scripts/pungsokdo.py import /path/to/extracted-images
```
