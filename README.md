# 조선의 하루

초등 사회 시간에 조선 시대 사람의 신분과 역할을 정하고, 모습을 꾸미고, 하루를 상상하는 활동입니다.

## 시작 화면

마을 배경과 움직이는 인물 앞에서 `시작하기`를 눌러 활동을 시작합니다. 처음 화면으로 돌아와도 현재 인물과 추첨 횟수는 보존됩니다.

## 활동 흐름

1. 신분 돌림판: 최대 네 번 뽑은 결과를 회차별로 표시하고 그중 하나를 선택합니다. 네 번째 추첨 뒤에도 자동으로 넘어가지 않으며 중간 확정도 가능합니다. 결과와 선택은 새로고침해도 보존됩니다.
2. 인물 정하기: 성별, 실제 역사 인물과 이름 추천, 직접 이름 쓰기, 신분별 대표 역할.
3. 꾸미기: 원본의 신체 비례·손·옷 주름을 보존한 24개 동작, 신분·성별과 관계없이 직접 고르는 의상·모자·색·표정·동작. 직업을 바꿔도 꾸민 모습은 유지됩니다.
4. 하루 이야기: 장소, 하루의 일과, 상상한 사건.
5. 완성: 인물 카드 PNG, 투명 배경 인물 PNG, 작품 JSON 저장.
6. 우리 반 풍속화: 최대 26명 배치, 이동·위치 고정, 겹침 알림과 빈자리 이동, 전체 PNG 저장.

## 수업에서 모으기

학생은 완성 화면에서 `우리 반에 보낼 작품 파일`을 내려받습니다. 선생님 기기에서 `우리 반 풍속화 → 작품 파일 가져오기`로 JSON 파일 여러 개를 모으고 배치합니다. 배치와 작품을 함께 JSON으로 보관하고 다시 가져올 수 있습니다.

작품은 브라우저의 localStorage에 저장됩니다. 다른 기기와 실시간으로 동기화되지 않으며 브라우저 데이터 삭제 시 없어질 수 있습니다. PNG와 JSON을 별도로 보관하세요. 로그인, 외부 데이터베이스, API 키는 필요 없습니다.

패들렛에는 내려받은 PNG를 직접 첨부합니다. 직접 첨부에는 API가 필요하지 않습니다. 자동 게시 기능은 포함하지 않습니다.

## 역사 자료와 그림

15~16세기의 사회를 중심으로 구성했으나 모든 복식·이름·역할이 해당 시기를 엄밀히 재현하는 것은 아닙니다. 추첨 확률은 **1717년 단성현 호주 구성비를 참고한 수업용 모델**입니다. 양반 18.6%, 중인 8.6%, 상민 45.6%, 노비 26.1%에서 미기재 1.1%를 제외하고 환산한 뒤 왕실 0.5%를 양반 몫에서 분리했습니다. 기본값은 왕실 0.5%, 양반 18.3%, 기술관 8.7%, 상민 46.1%, 천민 26.4%입니다. 중인/기술관, 노비/천민은 수업상 대응이며 같은 범위를 뜻하지 않습니다. 특정 지역의 호주 자료이므로 조선 전체 또는 활동 중심 시기인 15~16세기의 인구 비율로 해석하지 않습니다. 표의 확률은 1회 추첨 기준이며 네 번 중 선택한 최종 분포와는 다릅니다. 선생님의 사용자 설정은 유지됩니다. 돌림판은 이름을 읽기 쉽도록 20개의 같은 크기 조각으로 표시하지만, 추첨에는 신분별 가중치를 적용합니다. 오른쪽 화살표가 가리키는 이름과 추첨 결과는 일치합니다. 기술관과 후대 중인 명칭을 구분하고, 노비가 직업이 아닌 신분이라는 설명을 제공합니다.

기존 그림의 자연스러운 비례와 선 묘사를 유지하기 위해 원본 의상·손·얼굴·머리·동작 레이어를 사용합니다. 왕실 등의 문양과 관모, 생활 소품은 그 위에 더한 수업용 표현입니다. 상세 출처는 사이트의 `자료와 그림 출처`와 `ATTRIBUTION.md`를 참고하세요.

## 실행과 배포

별도 빌드가 없는 HTML/CSS/JavaScript 사이트입니다. 이 폴더를 정적 웹 서버로 열거나 `index.html`을 엽니다. 파일로 직접 열 때는 브라우저에 따라 로컬 저장 동작이 다를 수 있습니다.

배포 주소: https://chosenharu.vercel.app

소스 저장소: https://github.com/BAEPPY/chosenharu

사이트 수정과 배포는 이 GitHub 저장소와 Vercel만 사용합니다.

Vercel: Framework Preset `Other`, Root Directory 저장소 루트, Build/Install Command 비움, Output Directory `.`. `vercel.json`에 설정되어 있습니다. GitHub의 main 브랜치를 연결하면 새 커밋을 자동 배포할 수 있습니다.

## 구성

빌드 없이 실행하는 기능별 JavaScript 모듈입니다. `index.html`의 `defer` 순서로 데이터 → 공용 상태 → 기능 → `app.js`를 로드합니다. 공용 상태를 갖는 기존 인터페이스는 `js/core/context.js`에 모으고, 추첨의 순수 계산은 `DrawModel`로 분리했습니다.

- `app.js`: 초기 진입점
- `js/core/`: 상태, 정규화, 저장, 탐색, 렌더링, 이벤트 연결
- `js/components/`: 아이콘, 알림·대화상자, 인물 미리보기
- `js/data/`: 신분, 역할, 역사 인물, 이름, 의상, 동작, 역사 비율, 전통색
- `js/features/draw/`: 추첨 모델, 회차별 기록, 돌림판, 확률표, 설정, 음향
- `js/features/identity/`, `customize/`, `story/`: 단계별 화면과 동작
- `js/features/collection/`, `classroom/`, `export/`: 작품 보관·파일, 반 풍속화, PNG 저장
- `js/features/home/`, `help/`: 시작 화면과 도움말
- `styles/`: 디자인 토큰, 글꼴, 공용 요소, 기능별 스타일과 반응형 규칙
- `fonts/`: Pretendard Variable, 원본 Tossface 웹폰트와 라이선스 (외부 CDN 없이 제공)
- `art.js`, `art-layout.js`, `catalog.js`, `assets/`: 기존 그림 합성·부품

이전 버전에 저장하지 않았던 추첨 결과는 복원할 수 없어 ‘기록 없음’으로 표시합니다. 남은 횟수는 그대로이며, 당시 선택된 신분만 마지막으로 사용한 회차에 복원합니다.

## 검증

- `npm test`: 네 번 제한, 중복 결과, 선택 복원, 이전 저장 형식, 가중치 경계 검사 (Node 내장 테스트)
- `npm ci && npm run test:browser`: Chromium에서 추첨 → 선택 → 꾸미기 → 이야기 → PNG 저장 → 반 풍속화 및 320/390px 화면 확인
- 브라우저 테스트는 Python 정적 서버를 직접 시작하고 종료합니다. `CHROMIUM_PATH`로 Chromium 실행 파일 위치를 지정할 수 있습니다 (기본 `/usr/bin/chromium`).
