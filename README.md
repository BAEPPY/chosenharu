# 조선의 하루

초등 사회 시간에 조선 시대 사람의 신분과 역할을 정하고, 모습을 꾸미고, 하루를 상상하는 활동입니다.

## 시작 화면

학생용 시작 화면과 공동 교실에서 `새로 만들기`와 `이어 만들기`를 따로 선택합니다. 작성 중인 인물이 있으면 새로 만들기 전에 교체를 확인하며, 인물 모음과 공동 풍속화의 작품은 유지합니다. 이어 만들기는 새로고침하거나 풍속화에서 돌아온 뒤에도 마지막 편집 단계로 돌아갑니다. 처음 화면으로 돌아와도 1시간 미사용으로 초기화되기 전까지 현재 인물과 추첨 횟수는 보존됩니다.

## 활동 흐름

1. 신분 돌림판: 최대 네 번 뽑고 회차별 결과에서 하나를 선택합니다. 조각의 넓이는 현재 추첨 확률에 비례합니다.
2. 동작 정하기: 14개 동작 묶음에서 37개 동작 중 하나를 먼저 고릅니다.
3. 인물 정하기: 신분·성별별 실제 인물과 대표 역할에서 선택하거나 이름을 직접 씁니다.
4. 꾸미기: 신분과 역할에 허용된 의상·모자에서 색·표정을 고릅니다. 직업·성별에 맞는 의상에는 선택 전부터 작은 두루마리 모양의 `추천` 딱지가 표시됩니다.
5. 하루 이야기: 장소, 하루의 일과, 상상한 사건을 씁니다.
6. 완성: 동작에 어울리는 배경 중 하나를 무작위로 추천합니다. 다른 어울리는 배경으로 바꿀 수 있고, 배경을 포함한 인물 카드 PNG·작품 JSON과 투명 인물 PNG를 저장합니다.
7. 우리 반 풍속화: 새로 제작한 마을에 최대 26명을 끌어서 자유롭게 배치합니다. 겹침도 유지하며 아래쪽 인물이 앞에 보입니다. 방향키 이동·위치 고정·자리 정돈·전체 PNG를 지원합니다.

상단 단계 표시는 진행 상태만 보여 줍니다. 단계 이동은 하단 이전·다음 버튼을 사용합니다.

## 옷차림

25종의 의상을 고를 수 있습니다. 당의의 긴 앞자락, 활옷의 자수와 한삼, 원삼의 색동 소매, 노의의 원형 문양, 곤룡포의 가슴·어깨 용보, 면복의 폐슬, 단령의 흉배, 작업복·앞치마·두루치기를 각각 그립니다. 익선관·사모·면류관·탕건은 머리·모자에서 따로 고릅니다.

왕의 곤룡포·황룡포·면복·면류관은 왕 역할에, 세자의 곤룡포는 왕자·세자 역할에 한정합니다. 익선관은 왕·왕자·세자, 노의는 왕비·공주에게만 표시합니다. 왕실이 아닌 상민·천민·중인·양반은 이 전용 복식과 관모를 선택할 수 없습니다. 신분·성별·역할 변경이나 예전 작품 불러오기에서도 맞지 않는 선택을 교정하며, 공동 교실 API는 같은 규칙으로 부적합한 요청을 거부합니다. 혼례복으로 쓰인 활옷·원삼 등 나머지 선택지는 유지합니다. 규칙은 `js/data/wardrobe-policy.js`에서 브라우저와 서버가 공유합니다.

옷을 새로 고르면 해당 옷의 기본 배색이 적용되며, 선택한 옷의 색은 수정할 수 있습니다. 머리·표정·동작은 유지됩니다. 미리보기와 PNG는 같은 레이어를 쓰며 원본 파일을 수정하지 않습니다. 새 외곽선은 360px 좌표에서 2px, 주름선은 1.3px를 기준으로 원본과 맞춥니다. 색을 바꾸거나 저장·가져오기를 해도 동일하게 적용됩니다.

손은 피부색과 원본 윤곽선을 함께 복원합니다. 두 걷기 동작의 긴 소매는 실제 소매 끝에 손을 연결하고, 몸판 마스크로 끊겼던 소매 윤곽을 복원합니다. `tests/garment-hands.cjs`는 25종 의상 × 두 걷기 동작 × 피부색 5종의 손과 윤곽을, `tests/student-entry.cjs`는 새로/이어 만들기와 추천 딱지의 역할·성별 반영을 검증합니다. 두 검사는 로컬 서버를 실행한 뒤 `APP_URL`로 지정해 실행합니다.

- 인물 목록: `js/data/figures/`의 신분·성별별 파일, 레코드별 자료 링크
- 의상 데이터·배색: `js/data/outfits.js`, `js/data/garments.js`
- 의상 그림: `js/art/garment-*` (형태·주름, 문양, 소매, 평상복, 의례복, 선 기준, 동작별 좌표)
- 추가 관모: `js/art/headgear-court.js`
- 참고 자료: [국립고궁박물관 곤룡포](https://www.gogung.go.kr/gogung/pgm/psgudMng/view.do?menuNo=800065&psgudSn=358343), [구장복](https://encykorea.aks.ac.kr/Article/E0006005), [왕비의 소례복](https://dh.aks.ac.kr/wiki/index.php/왕비의_소례복), [활옷](https://dh.aks.ac.kr/~katd/wiki/index.php/활옷), 사용자가 제공한 복식·동작 참고 이미지

## 수업에서 모으기

학생은 완성 화면에서 `우리 반에 보낼 작품 파일`을 내려받습니다. 선생님 기기에서 `우리 반 풍속화 → 작품 파일 가져오기`로 JSON 파일 여러 개를 모으고 배치합니다. 배치와 작품을 함께 JSON으로 보관하고 다시 가져올 수 있습니다.

작품은 브라우저의 localStorage에 저장됩니다. 마지막 이용 후 1시간이 지나 다시 접속하거나 탭으로 돌아오면 인물·작품 모음·배치·추첨 설정이 초기화됩니다. 입력·클릭·이동 중에는 이용 시간이 갱신됩니다. 개인 배치판은 다른 기기와 동기화되지 않습니다. 아래의 공동 교실은 서버에 따로 저장하며 여러 기기에서 함께 편집할 수 있습니다. PNG와 JSON을 별도로 보관하세요. 학생·교사 계정 가입은 필요 없습니다. 공동 교실은 서버의 비공개 저장소를 사용하며, 접근 권한은 각 교실의 교사용·학생용 링크로 구분합니다.

패들렛에는 내려받은 PNG를 직접 첨부합니다. 직접 첨부에는 API가 필요하지 않습니다. 자동 게시 기능은 포함하지 않습니다.

## 역사 자료와 그림

인물과 복식은 조선의 여러 시기를 다루며, 황룡포는 대한제국 복식임을 선택지에 표시합니다. 모든 그림은 수업용으로 간략화한 표현입니다. 추첨 확률은 **1717년 단성현 호주 구성비를 참고한 수업용 모델**입니다. 양반 18.6%, 중인 8.6%, 상민 45.6%, 노비 26.1%에서 미기재 1.1%를 제외하고 환산한 뒤 왕실 0.5%를 양반 몫에서 분리했습니다. 기본값은 왕실 0.5%, 양반 18.3%, 중인 8.7%, 상민 46.1%, 천민 26.4%입니다. 노비/천민은 수업상 대응이며 같은 범위를 뜻하지 않습니다. 특정 지역의 호주 자료이므로 조선 전체 또는 다른 시기의 인구 비율로 해석하지 않습니다. 표의 확률은 1회 추첨 기준이며 네 번 중 선택한 최종 분포와는 다릅니다. 선생님의 사용자 설정도 활동 시간 동안 유지됩니다. 돌림판의 각 조각은 추첨과 같은 가중치를 사용합니다. 0% 조각은 생략하고, 100%이면 원 전체를 차지하며 작은 조각의 이름과 확률은 범례로 확인합니다. 오른쪽 화살표가 가리키는 이름과 추첨 결과는 일치합니다. 중인의 범위가 시기에 따라 달랐음을 안내하고, 노비가 직업이 아닌 신분이라는 설명을 제공합니다.

기존 그림의 자연스러운 비례와 선 묘사를 유지하기 위해 원본 의상·손·얼굴·머리·동작 레이어를 사용합니다. 왕실 등의 문양과 관모, 생활 소품은 그 위에 더한 수업용 표현입니다. 상세 출처는 사이트의 `자료와 그림 출처`와 `ATTRIBUTION.md`를 참고하세요.

## 공동 교실과 교사용 페이지

- 교사용 시작: 상단 **‘조선의 하루’ 배너를 연속 다섯 번** 누릅니다. 일반 화면에는 교사용 진입 버튼을 표시하지 않습니다. 직접 `#teacher` 또는 교사용 관리 링크로 접속해도 새 탭에서는 같은 동작이 필요합니다. 각 클릭 간격은 4초 이내이며 다른 버튼을 누르면 횟수가 초기화됩니다.
- 같은 탭에서 새로고침할 때는 진입 상태를 유지하고, 1시간 미사용으로 활동이 초기화되면 다시 잠급니다. 배너 동작은 화면 진입 절차이며, 실제 교실의 조회·관리 권한은 기존 교사용 토큰으로 서버가 검증합니다.
- 교실을 만들면 **교사용 관리 링크**와 **학생 참여 링크**를 별도로 제공합니다. 학생에게는 학생 참여 링크만 공유합니다.
- 교사는 학생들이 드래그하는 중의 이동을 보고, 인물을 선택해 이름·신분·역할·장소·하루 이야기·상상을 확인합니다. 전체 이동 잠금, 개별 위치 고정, 자리 정돈, 공동 PNG/JSON 저장을 지원합니다.
- 학생은 본인이 넣은 인물만 움직이거나 뺄 수 있습니다. 이 권한은 서버에서도 검증합니다. 다른 학생에게는 인물의 자세한 이야기 본문을 보내지 않습니다.
- 링크 참여 후 인물 만들기 도중 새로고침해도 교실 연결을 유지합니다. 교사용 링크는 같은 기기의 교사용 페이지에서 다시 열 수 있고, 다른 기기에서는 보관한 교사용 링크로 들어갑니다.
- 공동 작품은 개인 화면의 1시간 미사용 초기화와 별도로 서버에 보관됩니다. 교사가 학생 이동을 잠가도 작품 확인·다운로드는 가능합니다.
- 위치를 드래그하는 중에도 전송하며, 활성 화면은 약 1초 간격으로 변경을 확인합니다. 네트워크 장애 때 연결 상태를 표시하고 이동을 다시 전송합니다.

서버는 `api/classrooms.js`의 Node 함수와 `server/`의 권한·변경 처리로 구성합니다. 비공개 Vercel Blob에 교실 문서를 저장하고, 최신 원본 읽기와 ETag 조건부 쓰기(CAS)로 동시 변경을 합칩니다. 인스턴스별 메모리는 처리 중인 요청 묶음에만 사용하고, 저장 성공 전에 변경 완료를 응답하지 않습니다. 교실 상태·권한의 원본은 항상 비공개 저장소입니다. 배포 미리보기와 운영 교실은 별도 경로에 보관합니다. 비밀 접근키는 공개 파일이나 작품 JSON에 포함하지 않습니다.

## 실행과 배포

HTML/CSS/JavaScript 화면과 Node API로 구성합니다. `npm ci && npm run dev`로 로컬 공동 교실까지 실행합니다. 개발 서버는 `/tmp/joseon-classroom-dev`의 파일에 보관하고, 운영 API는 항상 연결된 비공개 Blob 저장소를 사용합니다. 정적 서버만 사용할 때는 개인 만들기·배치 기능만 동작합니다.

배포 주소: https://chosenharu.vercel.app

소스 저장소: https://github.com/BAEPPY/chosenharu

사이트 수정과 배포는 이 GitHub 저장소와 Vercel만 사용합니다.

Vercel: Framework Preset `Other`, Root Directory 저장소 루트, Install Command `npm ci`, Build Command `npm run verify:classroom-store`, Output Directory `.`. `vercel.json`에 설정되어 있습니다. GitHub의 main 브랜치가 자동 배포됩니다. `BLOB_READ_WRITE_TOKEN`은 프로젝트 저장소 연결로 서버 환경에 주입됩니다. 빌드 시 실제 연결 저장소에 임시 교실을 만들어 26명 동시 추가·이동·권한·CAS를 검증하고 임시 교실을 삭제합니다. 검증 실패 시 배포를 차단합니다.

## 구성

빌드 없이 실행하는 기능별 JavaScript 모듈입니다. `index.html`의 `defer` 순서로 데이터 → 공용 상태 → 기능 → `app.js`를 로드합니다. 공용 상태를 갖는 기존 인터페이스는 `js/core/context.js`에 모으고, 추첨의 순수 계산은 `DrawModel`로 분리했습니다.

- `app.js`: 초기 진입점
- `js/core/`: 상태, 정규화, 저장, 탐색, 렌더링, 이벤트 연결
- `js/components/`: 아이콘, 알림·대화상자, 인물 미리보기
- `js/data/`: 신분, 역할, 역사 인물, 이름, 의상, 동작, 역사 비율, 전통색
- `js/features/scenes.js`, `images/scenes/`: 동작별 추천 규칙과 이미지 생성 기능으로 제작한 개인 배경 6장·단체 마을 1장. 선택한 배경 ID와 동작을 작품에 저장해 화면·PNG·파일에서 유지합니다.
- `js/core/session.js`: 1시간 미사용 초기화, 다른 탭의 초기화 동기화, 기존 저장 형식의 최초 이용 시간 부여
- `js/features/draw/`: 추첨 모델, 회차별 기록, 돌림판, 확률표, 설정, 음향
- `js/features/identity/`, `customize/`, `story/`: 단계별 화면과 동작
- `js/features/collection/`, `classroom/`, `export/`: 작품 보관·파일, 반 풍속화, PNG 저장
- `js/features/home/`, `help/`: 시작 화면과 도움말
- `styles/`: 디자인 토큰, 글꼴, 공용 요소, 기능별 스타일과 반응형 규칙
- `fonts/`: Pretendard Variable, 원본 Tossface 웹폰트와 라이선스 (외부 CDN 없이 제공)
- `art.js`: 미리보기와 PNG 출력에 공통으로 쓰는 레이어 합성
- `js/art/`: 원본 부품 조회, 의상 선택, 문양, 관모, 생활 소품
- `art-layout.js`, `catalog.js`, `assets/`: 기존 그림·좌표 데이터
- `assets/poses/`, `js/data/pose-library.js`: 추가 12개 동작의 채색·피부 마스크·관모 좌표와 선택 목록
- `art-library/pungsokdo/`: 현대 물품이 없는 그림을 선별한 [원본 자료](art-library/pungsokdo/README.md). 새 동작의 PNG를 여기서 직접 불러오며 원본 출처와 제외 사유도 보관합니다.

추첨 횟수와 선택은 실제 회차별 기록으로만 복원합니다. 이전 버전의 횟수만 있거나 빈 회차를 포함한 잘못된 기록은 0회로 되돌립니다. 기존 인물·작품·이야기는 보존하며 ‘기존 인물 이어하기’로 계속할 수 있습니다. 인물 모음에서 불러오기도 추첨으로 세지 않습니다.
